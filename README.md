# CloudConvert - Online File Converter

A cloud-based file conversion platform similar to iLovePDF, built as an Engineering Cloud Computing curriculum project.

## Features
- 25+ file conversion tools
- PDF: Merge, Split, Compress, Convert, Watermark, Page Numbers, Rotate, Protect
- Images: Compress, Resize, Crop, Rotate, Convert formats
- Documents: Word to PDF, Excel to PDF, HTML to PDF, Text to PDF
- Conversions: JPG/PNG/WebP, CSV/Excel, and more

## Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **File Processing:** sharp, pdf-lib, mammoth, xlsx
- **Cloud:** Render.com (Free Tier)
